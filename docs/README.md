# Documentation Entry Point

Open this `docs` directory as an Obsidian vault and begin at [[00-Home|Growth Audit Project Knowledge Base]].

The vault includes product context, architecture diagrams, workflows, complete module catalogues, API and data references, integrations, local development, deployment, security, and environment configuration.

No Obsidian application settings are committed, so each contributor can use their own graph, theme, plugins, and workspace layout.
